# 深度动作捕捉

火山引擎 AI MediaKit 的独立声明式协议插件，提供视频节点的「深度动作捕捉」处理工具。它输出逐帧相对深度视频，不输出骨骼、BVH 或三维动画文件，也不需要在服务器安装推理模型。

## 管理员配置

1. 在后台插件管理中启用本插件，再在系统模型渠道选择「深度动作捕捉」协议。
2. Base URL 使用 `https://mediakit.cn-beijing.volces.com`，通过后台密钥字段设置 MediaKit API Key，不要把密钥放入 URL。
3. 此服务没有 `/models` 模型列表接口，手动添加模型 ID `standard`，能力为视频。模型使用处理模式 `depth_capture`，不出现在普通视频生成模型列表中。
4. 按已确认的供应商成本与平台积分换算设置按秒价格。源视频时长用于预扣，成功后按实际输出时长结算；不足一秒按一秒。没有可靠输出时长时进入账单核对，不按估算静默扣费。
5. 默认源视频上限为 60 秒，可在处理配置中调整，最大 600 秒。无需配置输出分辨率、画幅、帧率或音频开关。源资源必须已上传且属于当前用户，视频尺寸不超过 2K。

在画布中选择一个视频节点，点击工具栏首项「深度动作捕捉」，先建立连线和空结果节点；按「开始捕捉」才创建任务。处理结果由统一资源流程下载保存，原视频保持不变。

详见 [接口说明](docs/interface.md)。
