# 易支付

官方 `yingce.payment/v1` 支付插件。兼容常见易支付网关：V1/MD5 `mapi.php` 与 V2/RSA `/api/pay/create`，支持支付宝/微信/QQ 等通道。协议实现参考 [acg-faka](https://github.com/lizhipay/acg-faka)。

1.0.10 支持后台多选开放的支付方式，用户在同一易支付商户下选择具体方式。默认方式继续保留，历史订单仍按创建时的配置处理；实际可用方式以商户网关开通情况为准。

本地候选同时补齐 RPC 业务错误传递：保留插件明确返回的订单不存在、未支付和账单不存在类型，通用查单失败不推断为订单不存在。需配套更新宿主与插件执行文件；不新增 submit.php 或汇率功能。
