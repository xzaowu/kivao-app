# KIVAO 电商 Agent 工作台规划

拍法与分镜、草稿与 AI 策划、作品与多版本已进入本地体验。图视频共用同一工作台布局。历史提案见[电商创作体验改造方案](./ecommerce-workbench-redesign.md)。

## 一件商品，一个项目，多次创作

商家可以从一张图开始做套图，把满意的一张带入视频，用同一批商品资料试几个开场，最后在项目里找到每一版成品。

| 对象 | 内容和归属 | 用户在哪里操作 |
| --- | --- | --- |
| 商品项目 | 商品名称、商品原图与细节图、商家确认的商品事实。受众、平台、输出语言作为项目默认值，本轮可调整 | 共用素材栏。替换本轮首帧只更新本轮选择。AI 建议经用户采纳后才可用于脚本 |
| 本轮创作 | 记录所用商品素材、用途、目标和版本。图片草稿保存视觉方向与逐图方案；视频草稿保存拍法、镜头、口播与输出规格 | 同一「创作」视图内切换图片／视频，各自保留编辑位置和内容 |
| 任务与作品 | 每次提交关联项目、当时的方案与任务回执。成品可预览、派生为下一版，原版继续可查 | 「作品」按当前图片／视频模式展示。项目历史负责切换项目；生成记录跟随作品 |

图片已有项目版本、批次和恢复逻辑。视频支持从项目图片或素材库选帧、识图卖点建议、分镜策划和近期任务播放。素材库选图只作用于本轮视频，按资源 ID 引用已同步的原图。同一浏览器刷新可恢复视频草稿。未建项目的草稿按用户和当前创作会话保存，首次保存项目后可从该项目找回。新视频任务保存提交时的脚本、图片及其来源，派生的视频保留与来源作品的关联。[工作台入口](../../web/src/pages/ecommerce/index.tsx) · [视频草稿与任务](../../web/src/pages/ecommerce/product-video-workspace.tsx) · [现有电商功能](../content/docs/backend/ecommerce-agent.mdx)

图片和视频共用项目的「商品资料」。商家可把「有独立收纳盒」保存为商品卖点，每次创作时自行选用。「送给通勤的朋友」这样的开场文案可留在本条视频。

## 桌面与手机布局

```text
桌面 · 创作视图
项目名   [商品图片 / 商品视频]   [创作 / 作品]          历史   新建
────────────────────────────────────────────────────────────
左栏 · 约 1/3                 右栏 · 约 2/3
本轮商品图 / 视频首帧          图片：需求 → 视觉方向 → 逐图方案
商品素材缩略图                视频：用途 → 拍法 → 分镜脚本
商品资料、已确认卖点           只展开当前正在选择或编辑的内容
────────────────────────────────────────────────────────────
生成设置 · 当前规格                              本步费用   主操作
```

- **首次进入**时，桌面左栏可以选图，右栏可以选用途或直接写要求，顺序任选。从已有图片点「做成视频」时直接带入首帧。已知受众、平台和语言沿用项目值，按需展开修改。
- **切换到作品**时，顶部和项目上下文留在原位，主体给图片批次或视频播放。空历史不占创作首屏；有进行中任务时在「作品」旁显示数量。作品的下载、继续编辑等操作靠近对应成品。
- **手机**保留同一顶部切换。选图后将素材收成一行「缩略图 · 商品名 · 查看或更换」。拍法卡下展示当前镜头和时间线，点开场、细节或收尾即可逐镜查看与编辑。底部保留当前步骤的主按钮，规格在「生成设置」中展开。

## 视频流程与关键状态

1. **选用途。** 首版提供商品展示、场景种草、功能演示。后台模型与已知素材决定可执行的动作。需要额外素材时标明用途和必填性，例如开箱可补包装图。策划参考和实际发送给视频模型的首帧分别标识。
2. **选拍法。** 每类有三张拍法卡，用同一件示例商品表现不同构图。点卡可预览三段镜头，点「使用此拍法」才带入脚本。有手写想法可直接进脚本。进入脚本后可选「AI 分镜策划」，根据商品资料、卖点和当前镜头请求整条建议，或只改开场、细节、收尾之一。
3. **审脚本。** 一张镜头卡包含时间、画面动作和可选口播。例如耳机「场景种草」从通勤取出充电盒开场，中段按已确认特点展示佩戴或操作，结尾收回盒中。选「商品展示」则从开盖与耳机柄特写开始。用户能直接改任意镜头，已有手改时更换拍法须明确选择是否应用新稿。
4. **看报价再生成。** 现链路要求兼容系统模型、一张首帧、15 秒，一次提交生成整条视频。原生有声依模型能力开放。按钮写明「确认生成 1 条视频」，发生价格变化则重新确认。改脚本、切页、预览和恢复草稿都不启动生成。提交结果未确认时先查回执，保留草稿。
5. **从作品继续。** 可从近期任务回看提交时的三段脚本。播放成片时可留意见，例如「第 4 秒，给刷头一个近景」，带入新稿会打开细节镜头。改稿与生成整条视频分别操作。逐镜重拍需要分段生成和拼接能力。

## 实施顺序和验收

| 批次 | 范围 | 做到什么算通过 |
| --- | --- | --- |
| 1 · 拍法与分镜 | 共用工作台内增加三种视频用途、少量预设拍法、可编辑镜头卡。沿用现有报价与生成链路 | 同一张图选两种拍法能看出不同开场；可手填跳过选择；图视频切换保留编辑内容；桌面及 320、390 像素手机均能操作；浏览、选拍法和改稿产生零生成任务 |
| 2 · 草稿与 AI 策划 | 当前浏览器保存首帧选择、模型、卖点、拍法、三镜和口播。选整条或单镜策划，可补改稿要求，确认报价后生成建议 | 已在本地用隔离数据验证刷新恢复、项目与账号隔离，以及单镜采纳和撤销。识图、策划和视频分别报价。真实付费模型的输出质量与结算待验收 |
| 3 · 作品与多版本 | 把提交时的首帧、脚本和任务对应起来，提供「沿用脚本，换个开场」和按播放时间留意见 | 从成片找回当时的脚本；新稿和原片都能找到；失败或回执不明时可以恢复并核对 |
| 4 · 扩展玩法 | 参考复刻按素材拆解节奏；人物口播先预览人货同框，再确认声音；有分段任务和拼接能力后再评估逐镜重拍与送画布 | 每种玩法有自己的必需素材、模型能力和报价。换服装、换背景、换模特等可先走图片或画布，满意后再接视频 |

「参考视频复刻」可在浏览器拆解参考片的画面变化、回放选段，把拍法追加到具体一镜。「人物口播」可直接使用已有同框照，也可合成人物与商品首帧。商家可手写台词或依据选用的卖点请 AI 起草。两个已完成版本可在桌面并排审片，在手机上切换 A/B。可下载原片，已同步到素材库的成片也可送入已有画布。

独立音色、逐镜重拍与自动拼接留待后续。真实供应商的人物与商品保真度、口型同步和最终成本仍需另行验证。

## 从拍摄准备到审片

1. **定简报。** 先写给谁看、在哪里用，以及收尾要观众做什么。例如给通勤族演示随行杯，结尾让人对照杯架尺寸选择款式。三镜分别负责吸引注意、证明一个卖点和收尾。采用 TikTok 的开场、主体、结尾结构。[TikTok Creative Codes](https://ads.tiktok.com/business/library/Creative_Codes_ENG.pdf)
2. **决定谁出镜。** 纯商品演示可直接用商品首帧。人物演示先选模特和商品，写清拿法，确认手与包装比例后再配台词与声音。采用 HeyGen 商品植入的先确认同框图再做视频的顺序。[HeyGen 商品与模特同框](https://help.heygen.com/en/articles/12704854-product-placement-combine-a-product-with-an-avatar-in-a-video)
3. **对照镜头。** 三镜并排核对画面是否重复，逐镜指定参考图、景别、运镜与动作。拍摄清单让商家决定要看到哪些细节；模型使用的实际首帧与文字运动指令在提交前另行预览。[Adobe 拍摄准备](https://helpx.adobe.com/stock/contributor/help/artist-hub-migration/optimize-your-production-process.html) · [Runway 图生视频指南](https://academy.runwayml.com/guides/prompting-guide)
4. **审片与交付。** 提交前可改稿，提交后保留当时的简报、分镜参考和镜头设置。回看重点是同一件商品是否贯穿、台词是否有可见依据、收尾是否明确。现阶段一次生成整条 15 秒短片。逐镜生成后单独换镜，以及成片字幕、配音和混音仍是独立的后期工作。
