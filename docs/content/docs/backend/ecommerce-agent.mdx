电商 Agent 位于 `/ecommerce`，使用宿主现有登录、模型报价、任务系统和资源存储。上传商品图后可直接点「一键生成」，也可以先修改平台、语言、内容类型或张数。画面描述选填。详情图由 Agent 规划叙事与文案，涉及商品参数、功效和认证时需要有事实依据。

默认流程会显示策划和出图的预估积分。确认后，系统根据商品图直接策划，核对实际张数和报价，再提交图片任务。如果方案有待确认的商品事实、图片张数发生变化，或出图报价上涨，会停在方案供用户审阅。逐屏参考长图先生成方案，确定屏数后再确认出图。「更多设置」保留「先选视觉方向」和「先看方案」。作品完成后，可导出、拼成长图或转做商品视频。

商品图片在宽屏左侧设置，右侧显示示例、本轮进度或作品。窄屏保留「创作／作品」切换和底部生成按钮。商品视频单独保存草稿，也可通过 `/ecommerce?mode=video` 进入。

「带货视频」在同一页选 1–3 张同一商品的参考图、填写卖点和查看报价。默认的「达人口播推荐」由出镜人向买家讲解。商品图提供外观和细节，视频按分镜安排开场。拍法卡标明出镜口播、画外解说或无口播。有声拍法可以随视频生成所选语言的台词，也可以在「自定义脚本」中填写。

「人物口播」在一页准备首帧、填写台词和核对报价。默认使用已有同框图，可上传、从项目选取或从素材库选取。只有人物照和商品图时，切到「选模特合成」，分别核对两张原图再合成。使用前确认人物、商品和拿法，换图后需要重新确认。

「视频复刻」在一页准备一段参考视频和一张自己的商品图。默认「贴近原片」，借鉴镜头节奏、运镜与构图。选择「灵活改编」会沿用节奏，围绕新商品重新安排场景和动作。两份素材就绪并选到兼容模型后，可直接查看报价。需要指定出镜人时，可以用官方形象、自有图片或 AI 模特与商品合成一张参考图。

「投放设置」可选择市场地区、成片语言和视频比例。市场与语言用于 AI 简报、分镜、台词和成片指令，选项默认沿用项目设置；视频里的修改单独保存。比例按当前视频模型开放，只有固定比例时会直接显示。确认生成前可以再次调整，另起一版会恢复原作品保存的设置。

人物口播可直接选「直接推荐」「边用边讲」或「回答疑问」。每种方式都带三镜草稿，填好台词后即可查看视频报价。「AI 起草台词」在台词旁打开，可用已核实的卖点起草，采纳后才会替换原稿。想细调时，展开「自定义分镜」逐镜编辑，或展开「口播示例」预览。手写台词、所选首帧与分镜随视频草稿保存。

从已交付的商品图片点「做成视频」，该图会进入带货视频的商品参考图列表。「AI 分析卖点」按选中的整组商品图询价，确认后由后台指定的视觉模型一起读取，最多给出五条能从图中看到的特点。点选建议才会加入本轮卖点，已有文案可以继续编辑。

图片和视频共用项目里的「商品资料」。可手写已核实的卖点，也可勾选本轮文案中的个别卖点存入。每个项目最多保存 32 条，每条最多 280 字。切换创作方式或另做一版后，点「加入本轮」选用需要的条目。

如果提交卖点分析后断线，再次打开同一项目和商品图，可先核对原分析任务。找回结果后仍由商家挑选卖点，现有文案会保留。

带货视频可从设备、项目或素材库选取商品图。复刻使用商品参考图，人物口播使用已确认的人货同框首帧。手机上的复刻页面可直接查看或更换两份素材。所选素材随当前视频草稿和生成时的版本保存。

上传参考片后，浏览器按片长给出开头、中段和结尾三个对照片段，为 15 秒成片安排三镜。展开「自定义脚本」可以改画面和旁白。更换参考片或复刻方式会更新自动分镜，手动改过的分镜会保留，点「恢复自动分镜」并确认才会替换。想按原片的实际画面细调时，可展开「借鉴细节与片段」，拆解、回放并把选中的片段加到指定镜头。

达人口播推荐、买家问答、边用边讲和情景带货由人物出镜。日常种草、开箱分享和痛点解决用画外解说，使用演示和选购对照用动作讲清选购依据。三镜围绕商品、受众和已确认的卖点编排。带货与复刻的分镜、各创作方式的台词分别保存。选择无口播拍法会保留手写台词，切回有声拍法可以继续使用。

在脚本下展开「AI 分镜策划」，可选整条分镜，或只改开场、细节、收尾中的一镜。先填写商品资料或卖点，可补充改稿要求。点击「查看策划报价」并确认后，后台指定的整套策划模型会依据商品资料和现稿给出画面建议。点「采纳建议」才会修改选中的镜头；也可放弃，或在所采纳的镜头再次改动前点「撤销采纳」。口播继续由用户编辑。提交状态不明时，在同一标签页点「核对提交结果」查询已有任务。

刷新后可在同一浏览器恢复所选素材、商品图顺序、视频模型、卖点、用途、拍法、三镜和口播。未建项目时按账号和当前创作会话保存，首次建项目后随项目找回。本机草稿读写失败时可在页面上重试。

「带货视频」用 1–3 张图提供同一商品的不同角度或细节。启用分镜配图后，先按商品图顺序编号，再按镜头顺序加入额外参考图，重复使用同一图只计一次。报价按实际去重后的总张数和音频规格计算。三镜生成一条 15 秒视频。

复刻会同时向模型提交商品参考图和完整参考片。可选模型须能传递这两种素材，接受原片时长并支持 15 秒输出。填写旁白还需支持有声复刻。报价包含实际参考片时长，换片、改脚本或调整输出规格后需要重新核价。确认时会再次核对素材与报价。

参考片和借鉴要求随本机草稿保存，作品的原始脚本和派生稿也能找回这次的选择。素材失效后可在原稿中更换。卖点分析、分镜策划和视频生成分别报价、分别确认。视频模式的「作品」可播放本项目近期任务的成片。入口由电商、商品视频及视频生成开关共同控制。

在参考视频下点击「拆解参考片」，浏览器抽取真实画面，按明显变化估算最多六个片段。切点不明显时按时间展示。选中片段可单独回放，写下想借鉴的动作或机位，再追加到开场、细节或收尾。拆解可取消，无需模型报价。

口播的成片语言用于 AI 起草台词与画面文字。手写或采纳的台词会按原文、原顺序发送给视频模型。已确认的同框图作为第一帧，分镜指令要求同一位人物连续讲解并配合展示动作。改台词、换图或调整输出规格后需重新报价。刷新草稿或从作品改版均可继续使用原图、口播方式和台词。

只有单独的人物照片和商品图时，可以分别上传或从素材库选取，使用支持双图编辑的系统图片模型合成。确认一张图片的报价后生成，再决定是否用作口播首帧。「AI 起草台词」根据本轮卖点、输出语言和三段镜头另行报价。可先预览，再采用台词或撤销并恢复原稿。

在「人物口播」里合成同框图时，优先复用项目主模特，也可另选项目人物、素材库或九个内置人物形象。人物和商品分别选取，只有确定采用内置人物后才将该图导入当前用户的素材。可补充拿法或姿势，再检查合成图里的手、包装和商品比例。

「拍摄简报」的快捷建议按商品类别在本地生成。「AI 起草简报」另行报价，确认后将商品文字资料、平台、投放地区、语言、已确认的卖点和现有填写发送给策划文本模型。可逐项采纳受众、场景、收尾目标，也可以只填空白项。需要引用图片里的特点时，先采纳识图建议。

三镜故事板依次展示开场、细节和收尾，每镜可选一张项目图或素材库参考图，并独立指定景别、运镜和画面动作。「预览生成内容」列出视频输入、声音和拍摄指令。复刻和人物口播的分镜配图用于预演。

在商品视频的「作品」中展开「查看原始脚本」，可找回提交时的商品参考图或人物同框首帧、三段分镜、口播和输出规格。「沿用脚本，换个开场」把原稿复制到编辑区。也可以在播放到要调整的位置点「在此处留意见」，写下要求后进入对应镜头。意见随改稿保存在当前浏览器，由用户编辑分镜后再报价生成。新成片单独列出，「查看来源作品」可回到原片对照。已有另一份草稿时会先询问是否替换。旧任务缺少脚本记录时仍可播放成片。

按时间带入的修改意见也会预填到「AI 分镜策划」，默认选中对应镜头，点击确认策划后才提交。商品视频提交中断后，在同一标签页点「核对提交结果」，按本次提交编号检查本项目近期任务。核对期间可以继续编辑草稿，恢复已有回执不会再次发起生成。

有两条可播放且带原始脚本的成片时，作品页提供「对比成片」。桌面并排展示，手机切换 A/B，可按镜头定位，对照改过的分镜与台词。可以下载原片，也可把已同步到素材库的成片送到本人已有画布继续编辑。

商品图与借鉴图分别保存。参考方式支持商品自主策划、风格排版参考和详情长图逐屏参考。项目及其版本、任务回执与生成结果按用户隔离；删除项目保留资源及运行任务。作品区按批次展示本轮与之前的作品，可筛选、预览、修改单张、重试、下载与导出。

同商品连续创作从当前用户拥有的项目中读取最近 20 页已提交历史，继承商品资料与文案语气，以本轮要求覆盖旧要求。只有商品参考图有交集才关联历史，共享品牌 Logo、模特和借鉴图不能建立商品关联。历史文案不成为新规格的证据。普通商品策划逐屏分配机位、景别和购买问题，以 `displayAssignment` 随方案保存；输入新需求时保持已有结果与按钮稳定。

生成与策划统一使用安全边距、留白和商品避让约束；结果图按完整画幅显示。人物设定按目标地区与语言选择，每轮主动变化，同一套图保持身份一致；用户参考人物优先。肤质、景别和手部接触要求属于生成指导，不能替代成片检查。

平台选择与提示词共享随程序交付的平台资料，包含 SHEIN 在内的 36 个平台。已核实规则与待核实建议分别标记，待核实资料不能作为平台审核通过的保证。资料来源与使用边界见 [电商平台风格与图片规则](../overview/ecommerce-platform-rules)。

后台「电商 Agent」分组有两个页面。`/admin/ecommerce/agent`（电商 Agent 配置）先给出「上线检查」：电商 Agent 开放、图片生成开放、阶段模型可用（必需）和商品视频（可选），未完成项带去处；开关仍在「功能开放」修改。「阶段模型」只列实际执行的两个文本阶段：商品识别与视觉方向、整套策划（卖点文案、逐张分镜与生图提示词），各有主模型和备用模型，用与创作端相同的模型下拉，未开启识图的模型置灰并写明去「渠道管理 → 能力与参数 → 引用与限制」把「最多识别图片数」设为 1 以上；第三步出图使用用户在电商页选择的生图模型。配置仍保存在 `ecommerce_agent_orchestration_v1`：`director` 是整套策划；旧配置里 `director.reuse="marketing"` 时沿用 `marketing` 的模型，新页面保存时写入 `director` 并清空 `marketing`。未执行过的「视觉质检」阶段已移除。`/admin/ecommerce/library`（知识与技能）查看 KB01–KB19 知识域覆盖，管理固定来源同步、来源启停与条目审核。来源、版本和许可证随知识记录保留；覆盖数量不能作为各行业规则全部齐备的证明。检索使用数据库、关键词与规则，没有向量数据库依赖。

「知识与技能」页分视觉知识库、创作 Skills（`/admin/ecommerce/library/skills`）、行业品类（`/admin/ecommerce/library/categories`）三个标签；旧地址 `/admin/ecommerce-knowledge`、`/admin/ecommerce-skills`、`/admin/ecommerce-categories`均重定向到新页面。Skills 内置 61 个可执行创作方法包、许可证与版本信息，按商品和场景自动选择；管理员可启停、安装大包、改名并设置上游自动更新。行业字典包含 26 个根行业、64292 个中英文分类节点、搜索与祖先创作方法路由，覆盖分类不代表每个叶级品类均已逐项生成验收。

服务启动在离线包之后自动初始化 KB11–KB19、技能方法知识和行业类目。内置技能正文随二进制嵌入，类目字典随程序交付；新安装和升级不需要手工导入。管理员只需配置自己的文本、图片模型和两个阶段模型；实际模型调用仍使用宿主报价、权限与计费流程。

## 随程序交付的知识数据

`backend/internal/ecommerceknowledge/bundle/knowledge.json.gz` 随 Go 二进制嵌入 23 个知识源和 14740 条知识，包括 14739 条已通过、1 条已拒绝；KB01 有 11 条，KB02–KB10 各 10 条。`manifest.json` 记录来源、固定 commit、许可、分来源数量和 SHA-256，完整许可证与版权声明保存在数据包的来源记录中。

服务首次启动自动在一个事务内初始化离线数据，无需先访问 GitHub。安装摘要保存在 `system_settings` 的 `ecommerce_knowledge_bundle_receipt`；相同包再次启动直接跳过。版本变化时只合并缺失行，已有管理员修改、审核状态和停用设置保留。数据与安装记录一起提交或回滚，避免导入一半却被标记为完成。

维护命令在显式配置数据库位置后执行：`go run ./cmd/ecommerce-knowledge -bootstrap-bundled -admin <已有管理员ID>`。内置 KB01–KB10 的升级使用 `-bootstrap-builtin`，第三方固定来源在线同步使用 `-sync`。这些写操作需要已有管理员。数据包不包含具体部署的模型渠道绑定或凭据；部署后在四阶段配置中选择自己的模型。

HTTP 路由由 `backend/internal/handler/ecommerce.go` 和 `ecommerce_agent.go` 注册，业务在 `internal/app/ecommerce*`，持久化在 `internal/repository/ecommerce*`，领域契约与提示方法在 `internal/ecommerceagent` 和 `internal/ecommerceskills`。

`/api/ecommerce` 下提供项目、创意方向与技能提示接口；`/api/ecommerce/knowledge` 下提供知识与阶段模型管理接口，由服务端执行管理员权限校验。`/api/agent/quote`、`/api/agent/analyze`、`/api/agent/generate` 等接口提供独立 Agent 协议；`/api/canvas`、`/api/task` 下提供对应画布版本及任务查询接口。具体请求与响应以 handler 和前端 API 类型为准。管理员权限与用户资源归属均在服务端校验。

迁移 79 新增 `ecommerce_projects`、`ecommerce_knowledge_sources`、`ecommerce_knowledge_entries`、`ecommerce_creative_recommendations`、`ecommerce_agent_analyses`、`ecommerce_agent_runs`、`ecommerce_agent_pages`、`ecommerce_agent_canvas_versions`，包括知识域索引。保留上游 1–78 的迁移身份。电商图片读取使用 `ecommerce-export`，仅允许当前用户拥有的、32 MB 以内的 PNG、JPEG、WebP 原图，经受限同源流读取。

本次功能未包含旧版通用画布的一键详情／复刻节点，也不引入品牌、登录注册、支付充值或部署定制。真实浏览器、付费生成及已有部署的完整升级流程仍需人工验收；自动化数据库迁移和初始化检查不能代替这些验收。
