## 后续安全边界

- 当前 main 比生产源码另有 14 个后续提交；首发分支不覆盖 main，main 不经兼容评估不直接发布。
- 禁止使用官方 latest、官方安装脚本或 Host Updater 覆盖自有镜像；保留 PostgreSQL、Redis、数据/key 与反代。
- 每次 Compose 操作必须带上 Agent init overlay。首发旧 Agent 的一次性强制终止授权已经使用，不能复用。
- r1 构建/锁定脚本固定首发身份；下一版须另行审查候选源码构建与成对镜像锁，回滚优先回到当前 KIVAO r1。
