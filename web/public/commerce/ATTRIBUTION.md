# 电商选择器图标

已收录的品牌轮廓来自 Simple Icons 16.36.0（CC0-1.0），具体许可随 `platforms/LICENSE-simple-icons.md` 保留。来源：https://github.com/simple-icons/simple-icons 。品牌名称与标识的商标权属于各权利人，使用于平台识别。

无对应轮廓的平台使用本项目绘制的文字标识，便于辨识，不表示官方合作或背书。

国旗来自 flag-icons 7.6.0（MIT），版权与许可保留在 `flags/LICENSE.txt`。来源：https://github.com/lipis/flag-icons 。国旗为语言市场的视觉提示，输出语言与目标地区仍由用户独立选择。

`video-approaches/` 的九张 WebP 图是为商品视频工作台生成的虚构香薰瓶拍摄示意图，用于比较构图与镜头顺序。

`sales-video/` 的九张 WebP 封面为本项目生成的虚构带货场景，分别展示人物口播、画外解说和无口播的商品演示。

`video-examples/` 的无声分镜预演和封面由上述香薰瓶示意图、`examples/diffuser-white-v1.png` 以及内置出镜人素材 `ecommerce-models/cn-woman.png` 剪辑而成，用于对照取景与节奏。
